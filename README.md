## **Problem Statement**

The Line Editor is a command-line text editor developed in the C programming language. The application allows users to manage a document one line at a time through a menu-driven terminal interface.
The project demonstrates the use of C programming concepts including functions, strings, arrays of character pointers, dynamic memory allocation, input validation, and memory deallocation.

## **Features**

1. Insert line
2. Delete line
3. Display document

## **Data Structure**

The editor uses an array of strings to store document lines.

```c
char lines[100][200];
```

## **Compilation**

```bash
gcc line_editor.c -o line_editor
```

## **Run**

